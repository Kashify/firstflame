# First Foods Spices — Luxury D2C 3D E-Commerce

A luxury 3D e-commerce website for **First Foods Spices**, built with TanStack Start, React 19, Three.js, React Three Fiber, Framer Motion, and Tailwind CSS v4.

## Features
- **3D WebGL Floating Spice Studio**: Atmospheric floating 3D Indian spices (Star Anise, Green Cardamom, Cinnamon bark roll, Black Peppercorns, and Saffron strands).
- **3D Packaging Inspector**: Interactive 360° product jar model viewer on product detail pages.
- **Quick View Modal & Sticky Add to Cart**: Fast product inspection and mobile-optimized sticky cart bar.
- **Spice Sommelier Quiz**: Guided taste profile finder for custom spice curations.
- **SEO & JSON-LD**: Rich Google search schema for products.

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```

## Built With
- **Framework**: TanStack Start & React 19
- **Styling**: Tailwind CSS v4
- **3D & Motion**: Three.js, React Three Fiber, Drei, Motion
- **Tooling**: Vite & Nitro
