# First Foods Spices — Codebase Guidelines

This is an e-commerce web application for **First Foods Spices**, built with TanStack Start, React 19, Vite, Tailwind CSS v4, and Three.js / React Three Fiber.

## Project Structure
- `src/routes`: TanStack Start file-based routing (`index.tsx`, `product.$slug.tsx`, `cart.tsx`, `checkout.tsx`, etc.).
- `src/components`: UI components, Quick View, and 3D WebGL scenes (`src/components/3d`).
- `src/lib`: Data models, state store (`store.tsx`), and catalog dataset (`catalog.ts`).
- `src/styles.css`: Tailwind CSS v4 design tokens and custom luxury utility classes.
